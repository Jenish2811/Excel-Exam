# 📊 Excel Dashboard Project

## 📌 Electronic Sales of 2023-2024.
**Jenish Patel -- Excel Dashboard**

## 📖 Overview

This project is an interactive Microsoft Excel Dashboard designed to
analyze and visualize data effectively using charts, pivot tables,
slicers, and key performance indicators (KPIs).

The dashboard provides meaningful insights through dynamic visuals and
automated calculations, making it easy to interpret large datasets.

------------------------------------------------------------------------

## 🎯 Objectives

-   Transform raw data into interactive visual insights\
-   Create dynamic charts and pivot tables\
-   Enable filtering using slicers\
-   Present KPIs clearly and professionally\
-   Improve decision-making through data visualization
